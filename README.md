# 校园失物招领

软件工程结对作业第二次——程序实现。

## 一、项目简介

一个校园失物招领平台，支持：

- 发布寻物 / 招领信息
- 关键词搜索（物品名称、描述、地点）
- 按类型 / 类别 / 状态筛选
- 查看「我的发布」
- 查看详情、一键复制联系方式
- 发布者标记「已找到」/「已归还」
- 数据持久化（localStorage）

## 三、使用说明

### 环境要求

- 谷歌浏览器（Chrome）
- Node.js（只在跑单元测试时需要）

### 运行网页

1. 克隆仓库到本地：
   ```bash
   git clone https://github.com/Sakura-x000/102401302-102401304.git
   ```
2. 进入项目目录，双击 `index.html`，用谷歌浏览器打开即可。
3. 无需任何后台或额外环境。

### 功能操作

- **发布信息**：点右上角「+ 发布信息」，填完点「发布」。
- **搜索**：顶部搜索框输入关键词，点「搜索」。
- **筛选**：通过类型 / 类别 / 状态下拉框筛选。
- **我的发布**：点「我的发布」，只看自己发布的信息。
- **重置**：点「重置」清空所有筛选条件。
- **查看详情**：点任意卡片，弹出详情弹窗。
- **复制联系方式**：详情弹窗里点「复制联系方式」。
- **标记已找到 / 已归还**：在详情弹窗里，仅自己发布的信息可操作。
